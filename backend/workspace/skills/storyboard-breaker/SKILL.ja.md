# ストーリーボード設計ガイド

ストーリーボードは脚本シーンの実行計画である。後続のストーリーボード画像、動画プロンプト、動画生成を拘束するため、具体的で撮影可能かつ審査可能でなければならない。

## 階層の定義

| 階層 | 意味 | ルール |
|---|---|---|
| 脚本シーン | 脚本の `## S01 \| 内景 · 場所 \| 時間帯` | 1つの脚本シーンを1個以上のパートに分ける。一言のシーン目的（summary）を書く。例：「犠牲・信念の極み：重傷で捕らえられても志を曲げない」 |
| パート | 1回の動画生成 | **4〜15秒**、1つのシーン（scene_id）内でのみ起こる。**最大4コマ**、超える場合は次のパートに分ける |
| カット | カット番号の変化 = 切り替え（ハードカット） | 各カットにショットサイズ、アングル、カメラワーク、目的、パート内の開始／終了秒を書く。タイムラインは隙間なくつながり、最後のカットの終了秒 = パートの尺 |
| 拍 | 同じカット内の連続動作、拍番号 1A/1B/1C | 同カット番号の A/B/C は切り替えず、動作やカメラが続くだけ。**1拍 = ストーリーボード上の1コマ**。各カット1〜3拍 |

## パートの分け方

1. **拍の識別**：感情と物語の転換（導入・きっかけ・対立・爆発・余韻）で分け、拍の境界で優先的に区切る。因果の連鎖（前振り・出来事・反応）はなるべく同じパートに残す
2. **総量の見積もり**：目標総尺 ≈ 脚本の文字数 ÷ 500字/分。空ショット・オープニングは4〜6秒、物語パートは8〜12秒、感情の山場は12〜15秒でテンポを落とす
3. **セリフの下限**：パートの尺 ≥ セリフとナレーションの文字数 ÷ 4.5字/秒 ＋ 演技の余裕2秒。収まらなければパートを分ける
4. **つなぎ**：各パートに「このパートの開始」（start_state）と「このパートの終了」（end_state）を書く——どちらも目に見える画面の状態（誰がどこで何をしていて、光はどうか）。次のパートの開始は前のパートの終了を受け継げること

## カットの書き方

- **size ショットサイズ**：大遠景／遠景／全景／ミディアム／ミディアムクローズアップ／クローズアップ／大クローズアップ
- **angle アングル**：カメラの方向＋高さ。例：「高所から山道沿いに見下ろす」「正面やや斜め、目線の高さ」「地図机に斜めに向き、胸の高さ」
- **movement カメラワーク**：フィックス／プッシュ／プル／パン／横移動／フォロー／手持ち、速度と着地点まで書く。例：「フィックス後、ごくゆっくり寄る」
- **purpose カットの目的**：このカットで観客に何を感じさせるか。例：「作品最初の息づかい：冷たく、静かで、低く押さえる」

## 拍（各コマ）の書き方

- **frame 画面**：コマを止めた瞬間の構図——誰が画面のどこに、向き、表情、前景と背景の関係（ストーリーボード画像用、1つの完結した画面として書く）。**人物のいないコマは「空镜：」で始め、カメラが捉える物を明記する**（例：「空镜：雨粒が泥の水たまりに落ち、小さなしぶきが上がる」）。「横向き」「振り返る」など人物の動作と読める語は書かない
- **action 動作**：この拍で起こる目に見える変化（人物・小道具・環境）、具体的な動詞で、感情は見える行動に変換する
- **camera**：同カット継続中のカメラの変化（省略可）
- **sound 音**：環境音、動作音、音楽。「緊張」「悲しい」だけにしない
- **narration / dialogue**：ナレーションとセリフ。脚本からのみ取り、それが起こる拍に書く
- **subject_arrow 赤矢印**：人物／小道具の動きの短い注記。例：「行進」「なぞる」「振り向く」。なければ省略
- **camera_arrow 青矢印**：カメラの動きの短い注記。例：「ゆっくり横移動」「光の縁の顔へゆっくり寄る」。なければ省略

## 紐付けのルール

- `scene_id`：パートが起こるシーン。read_storyboard_context の scenes から選び、一致するなら必ず記入する
- `character_ids`：パート内で登場する、見える、話すキャラクターはすべて紐付ける。空ショットは空でよい
- `prop_ids`：使われる、受け渡される、クローズアップされる、または画面で明らかに見えて物語上意味のある重要な小道具
- 紐付けた素材はストーリーボード画像と動画生成の参照画像になり、人物・シーン・小道具の外見の一貫性を保つ

## 品質要件

- 各コマは単独で描けること：人物の位置、向き、光まで具体的に書き、抽象的な感情を書かない
- パート内のカットとカットの間には明確な切り替えの理由（情報・感情・主体の変化）があること
- セリフとナレーションは起こる順に対応する拍に置き、脚本のセリフを漏らさない
- save_boards は尺、タイムライン、拍番号、コマ数、セリフ下限を検証して warnings を返す。修正してそのシーンを再保存する
