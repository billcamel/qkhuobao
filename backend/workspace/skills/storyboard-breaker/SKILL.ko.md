# 스토리보드 설계 가이드

스토리보드는 대본 장면의 실행 계획입니다. 이후의 스토리보드 이미지, 비디오 프롬프트, 비디오 생성을 제약하므로 구체적이고, 촬영 가능하며, 검토 가능해야 합니다.

## 계층 정의

| 계층 | 의미 | 규칙 |
|---|---|---|
| 대본 장면 | 대본의 `## S01 \| 실내 · 장소 \| 시간대` | 대본 장면 하나를 1개 이상의 구간으로 나눔. 한 줄 장면 목적(summary)을 씀. 예: 「희생·신념의 극한: 중상으로 포로가 되어도 뜻을 굽히지 않는다」 |
| 구간 | 비디오 생성 1회 | **5~15초**, 하나의 장면(scene_id) 안에서만 일어남. **최대 4칸**, 넘으면 다음 구간으로 나눔 |
| 컷 | 컷 번호 변경 = 컷 전환(하드 컷) | 컷마다 화면 크기, 앵글, 카메라 워크, 목적, 구간 내 시작/끝 초를 씀. 타임라인은 빈틈없이 이어지고 마지막 컷의 끝 초 = 구간 길이 |
| 박 | 같은 컷 안의 연속 동작, 박 번호 1A/1B/1C | 같은 컷 번호의 A/B/C 는 컷하지 않고 동작이나 카메라가 이어질 뿐. **1박 = 스토리보드의 1칸**. 컷마다 1~3박 |

## 구간 나누기

1. **박자 식별**: 감정과 서사의 전환(도입·계기·대립·폭발·여운)으로 나누고, 박자 경계에서 우선 자름. 인과 사슬(복선-사건-반응)은 가능한 한 같은 구간에 둠
2. **총량 잡기**: 목표 총 길이 ≈ 대본 글자 수 ÷ 500자/분. 공샷·오프닝 5~6초, 서사 구간 8~12초, 감정 절정 12~15초로 템포를 늦춤
3. **대사 하한**: 구간 길이 ≥ 대사와 내레이션 글자 수 ÷ 4.5자/초 + 연기 여유 2초. 들어가지 않으면 구간을 나눔
   - **각 컷에도 그 컷의 대사가 들어가야 함**: 컷 길이 ≥ 그 컷의 대사와 내레이션 글자 수 ÷ 4.5자/초 + 1초. 실측 결과 비디오 모델은 대사를 끝까지 말하는 것을 우선해 너무 짧은 컷은 스스로 늘리고, 이후 컷 전환 지점이 모두 밀려 타임라인과 맞지 않게 됨
4. **연결**: 구간마다 「이 구간 시작」(start_state)과 「이 구간 끝」(end_state)을 씀 — 둘 다 눈에 보이는 화면 상태(누가 어디서 무엇을 하고 있고 빛은 어떤지). 다음 구간의 시작은 앞 구간의 끝을 이어받을 수 있어야 함

## 컷 작성법

- **size 화면 크기**: 익스트림 롱 / 롱 / 풀 / 미디엄 / 미디엄 클로즈업 / 클로즈업 / 익스트림 클로즈업
- **angle 앵글**: 카메라 방향 + 높이. 예: 「높은 곳에서 산길을 따라 내려다봄」「정면 약간 측면, 눈높이」「지도 탁자를 비스듬히, 가슴 높이」
- **movement 카메라 워크**: 고정 / 푸시 / 풀 / 팬 / 트럭 / 팔로우 / 핸드헬드, 속도와 도착점까지 씀. 예: 「고정 후 아주 천천히 다가감」
- **purpose 컷 목적**: 이 컷으로 관객이 무엇을 느끼게 할지. 예: 「작품의 첫 호흡: 차갑고, 고요하고, 낮게 눌러둠」

## 박(각 칸) 작성법

- **frame 화면**: 칸을 멈춘 순간의 구도 — 누가 화면 어디에, 방향, 표정, 전경과 배경의 관계(스토리보드 이미지용, 하나의 완결된 화면으로 씀). **인물이 없는 칸은 「空镜：」로 시작하고 카메라가 담는 사물을 명확히 씀**(예: 「空镜：빗방울이 진흙 웅덩이에 떨어져 작은 물보라가 튐」). 「옆으로 향함」「돌아봄」처럼 인물 동작으로 읽히는 말은 쓰지 않음
- **action 동작**: 이 박에서 일어나는 눈에 보이는 변화(인물·소품·환경), 구체적인 동사로, 감정은 보이는 행동으로 바꿈
- **camera**: 같은 컷이 이어질 때의 카메라 변화(생략 가능)
- **sound 소리**: 환경음, 동작음, 음악. 「긴장」「슬픔」만 쓰지 않음
- **narration / dialogue**: 내레이션과 대사. 대본에서만 가져오고 그것이 일어나는 박에 씀
- **subject_arrow 빨간 화살표**: 인물/소품 움직임의 짧은 표기. 예: 「행진」「훑음」「돌아섬」. 없으면 생략
- **camera_arrow 파란 화살표**: 카메라 움직임의 짧은 표기. 예: 「천천히 트럭」「빛 가장자리의 얼굴로 천천히 다가감」. 없으면 생략

## 바인딩 규칙

- `scene_id`: 구간이 일어나는 장면. read_storyboard_context 의 scenes 에서 고르며, 매칭되면 반드시 기입
- `character_ids`: 구간에 등장하거나 보이거나 말하는 캐릭터는 모두 바인딩. 공샷은 비워도 됨
- `prop_ids`: 사용되거나, 건네지거나, 클로즈업되거나, 화면에 뚜렷이 보이며 서사적 의미가 있는 핵심 소품
- 바인딩된 소재는 스토리보드 이미지와 비디오 생성의 참조 이미지가 되어 인물·장면·소품 외형의 일관성을 유지함

## 품질 요구 사항

- 각 칸은 단독으로 그릴 수 있어야 함: 인물의 위치, 방향, 빛까지 구체적으로 쓰고 추상적인 감정을 쓰지 않음
- 구간 안의 컷과 컷 사이에는 명확한 전환 이유(정보·감정·주체의 변화)가 있어야 함
- 대사와 내레이션은 일어나는 순서대로 해당 박에 두고, 대본의 대사를 빠뜨리지 않음
- save_boards 는 길이, 타임라인, 박 번호, 칸 수, 대사 하한을 검증해 warnings 를 반환함. 수정 후 해당 장면을 다시 저장함
