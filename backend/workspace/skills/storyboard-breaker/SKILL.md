# 故事板设计指南

故事板是剧本场景的落地方案：它约束后续的故事板出图、视频提示词与视频生成，必须具体、可拍、可审核。

## 层级定义

| 层级 | 含义 | 规则 |
|---|---|---|
| 剧本场景 | 剧本中的 `## S01 \| 内景 · 地点 \| 时间段` | 一个剧本场景拆成 1 到多段；写一句话场景目的（summary），如「牺牲·信念的极致：陈树湘重伤被俘，断肠明志」 |
| 段 | 一次视频生成 | **5-15 秒**，只发生在一个场景（scene_id）内；**最多 4 格画面**，超出就拆成下一段 |
| 镜 | 镜号变化 = 切镜（硬切） | 每镜写景别、角度、运镜、镜头目的、段内起止秒；时间轴首尾相接，最后一镜的结束秒 = 段时长 |
| 拍 | 同一镜内的连续动作，拍号 1A/1B/1C | 同镜号 A/B/C 不切镜，只是动作推进或镜头持续运动；**一拍 = 故事板上的一格画面**；每镜 1-3 拍 |

## 拆段方法

1. **节拍识别**：按情绪与叙事转折（建立、触发、对抗、爆发、余韵）划分，节拍边界优先切段；一条因果链（铺垫-发生-反应）尽量留在同一段
2. **总量锚定**：目标总时长 ≈ 剧本字数 ÷ 500 字/分钟；空镜/片头 5-6 秒，叙事段 8-12 秒，情绪爆点 12-15 秒且节奏放慢
3. **台词下限**：段时长 ≥ 段内台词与旁白字数 ÷ 4.5 字/秒 + 2 秒表演余量，装不下就拆段
4. **衔接**：每段写「本段开始」（start_state）与「本段结束」（end_state）——都是一句可见的画面状态（谁在哪、在做什么、光线如何），下一段的开始必须能接上上一段的结束

## 镜的写法

- **size 景别**：大远景 / 远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写
- **angle 角度**：机位方向 + 高度，如「自高处沿山路俯望，齐高空」「正面偏侧，齐眼高」「斜对地图桌，齐胸高」
- **movement 运镜**：固定 / 推 / 拉 / 摇 / 横移 / 跟拍 / 手持随行，写出速度与落点，如「固定后极缓推近」「手持随行，带一点雨里的呼吸感」
- **purpose 镜头目的**：这一镜要让观众感受到什么，如「全片第一口气息：冷、静、压得低」

## 拍（每一格画面）的写法

- **frame 画面**：这一格定格时观众看到的构图——谁在画面哪里、朝向、神态、前后景关系（用于故事板出图，写成一句完整画面）。**没有人物的格以「空镜：」开头，写清镜头对准的物体**（如「空镜：雨点砸进泥水坑，溅起细小水花」），不要写「侧对」「回望」这类会被理解成人物动作的词
- **action 动作**：这一拍里发生的可见变化（人物、道具、环境），动词具体，情绪转为可见描写
- **camera**：同镜持续时运镜的变化（可省略）
- **sound 声音**：环境音、动作音、音乐，不要只写「紧张」「悲伤」
- **narration / dialogue**：旁白与台词，只能来自剧本，写在它发生的那一拍
- **subject_arrow 红箭头**：人物/道具动作方向的短标注，如「行进」「划过」「转身」，没有就省略
- **camera_arrow 蓝箭头**：摄影机运动的短标注，如「缓慢横移」「缓慢推近到光缘上的脸」，没有就省略

## 绑定规则

- `scene_id`：段落发生的场景，必须取自 read_storyboard_context 的 scenes，能匹配就必须填
- `character_ids`：段内出场、被看见、说话的角色都要绑定；空镜可为空
- `prop_ids`：被使用、交接、特写或明显可见且对叙事有意义的关键道具
- 绑定的素材会作为故事板出图与视频生成的参考图，保证人物、场景、道具外观一致

## 质量要求

- 每格画面都要能单独画出来：具体到人物位置、朝向、光线，不写抽象情绪
- 同一段内镜与镜之间要有明确的切镜理由（换信息、换情绪、换主体）
- 台词与旁白按发生顺序落在对应的拍里，不遗漏剧本台词
- save_boards 会校验时长、时间轴、拍号、格数与台词下限并返回 warnings，修正后重新保存该场景
